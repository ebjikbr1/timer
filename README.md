# Контроль торможения

Мобильная страница с ручной фиксацией действий и голосовыми уведомлениями. В `site/audio/` уже включены 11 записанных команд. Сайт загружает их заранее и не запрашивает микрофон.

## Локальная проверка

```sh
npm start
```

Сервер использует переменную `PORT` (по умолчанию 3000).

## Обновить записи

В локальной версии страницы откройте «Настроить голосовые записи» и нажмите «Скачать все записи одним файлом». Затем выполните:

```sh
node scripts/import-voice-export.cjs /path/to/taimer-voice-recordings.json
```

Команда заменит аудиофайлы в `site/audio/` и обновит манифест. Без записи для конкретного события используется синтезированный голос браузера.
